# 5G / APN / Dual-SIM Troubleshooting Checklist

## First checks

- Confirm the SIM/eSIM is active and not suspended.
- Check whether the plan supports 5G, roaming, hotspot sharing, or data add-ons.
- Verify default mobile data SIM on dual-SIM phones.
- Restore carrier APN defaults if a custom APN causes instability.
- Compare indoor/outdoor performance to identify weak coverage or congestion.
