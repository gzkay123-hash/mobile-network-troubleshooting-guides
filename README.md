## Troubleshooting order

1. Check account/package status and whether service is suspended or limited.
2. Confirm APN, 5G/4G mode, default data SIM, roaming, and hotspot settings.
3. Test another location to separate coverage issues from device settings.
4. Reset network settings only after recording WiFi passwords and key settings.
5. For carrier rules, pricing, or roaming availability, rely on official carrier pages or customer service.

This repository is an educational checklist and does not represent any carrier.
